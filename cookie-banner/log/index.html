Change log

What changed in each released version of the LangKamel app, and how to confirm the change on your own store.

Current version 1.0.1 · 27 August 2026

1.0.1

27 August 2026

Fixed

A paid feature could stay locked after the subscription was approved

After approving a Basic or Pro subscription, the feature that plan unlocks could keep showing as Locked, as though the store were still on Free. The app's entitlement check was excluding the very subscription that had just been approved, so the app read the store as unsubscribed while Shopify had it as active.

Entitlement checks now count every active subscription on the store. A plan takes effect as soon as Shopify confirms it, on the first page load after approval.

How to confirm Upgrade to Basic from the app's settings page and approve the charge. On return, the Opt-in optimisation card reads Active — no reload, no waiting period. Downgrading and re-upgrading returns the card to Locked and back to Active in step with the subscription.

Fixed

The subscription approval screen could open blank on the first click

The app's server was allowed to sleep while idle. A first click after an idle period had to wait for that server to start, and could time out before Shopify's approval screen was reached — which showed as a blank frame rather than an error. A second click usually worked, because the first one had woken the server.

One server instance now stays running continuously, so there is no start-up delay to land in and the approval screen is reached on the first click.

How to confirm Leave the app untouched for several minutes, then click an upgrade button. Shopify's subscription approval screen appears on the first click, with no blank frame.

Fixed

Opt-in status could read Inactive for one page load after an upgrade

Immediately after an upgrade, the Opt-in optimisation card could report Inactive for a single page load and correct itself on the next one. The card was reading its status before the newly approved plan had been recorded. It now reads it afterwards, and is correct on the first render.

How to confirm Approve an upgrade to Basic and read the Opt-in optimisation card on the page you land on, without reloading. It reads Active.

Unchanged

No change to consent behaviour, stored data, or plans

This version touches only how the app recognises an approved subscription and how quickly it starts. The consent banner, the categories offered, the consent records written, the CSV audit export, and what each plan includes are all unchanged. Nothing about this release alters what is stored about a visitor — see the privacy page.

This log covers changes to the LangKamel app for Shopify. It does not cover changes to this website.

See the plans for what each tier includes, or the privacy page for what the app records. Questions: support@langkamel.com.
